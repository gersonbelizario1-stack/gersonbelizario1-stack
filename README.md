### vibecoder — construo o que preciso, do jeito que dá certo.

Não venho de uma trilha "engenheiro de software clássico". Venho de ter um problema real e resolver ele — testando, quebrando, ajustando, até o app funcionar de verdade em produção.

```
ideia → prototipo → quebra → conserta → funciona → repete
```

## 🚀 O que eu construo

Apps reais, pra uso real. Não protótipo de portfólio — coisa que roda no meu celular todo dia.

**Em destaque:** [profile-manager](https://github.com/gersonbelizario1-stack/profile-manager) — gestão de clientes, contas e perfis de streaming, PWA instalável, com notificações push de verdade (funcionam até com o app fechado), backup automático e banco protegido por RLS.

- **Deploy:** Vercel
- **Copiloto:** Claude — não escrevo tudo sozinho, e não tenho vergonha disso
